# 💱 Conversor de Moedas

Um simples **Conversor de Moedas** feito com **HTML, CSS e JavaScript puro**, que utiliza a **ExchangeRate API** para obter taxas de câmbio atualizadas em tempo real.

## 🚀 Funcionalidades

- Conversão entre diversas moedas do mundo.  
- Interface simples, responsiva e intuitiva.  
- Atualização automática das moedas disponíveis via API.  
- Cálculo instantâneo do valor convertido.

## 🧠 Tecnologias Utilizadas

- **HTML5** – Estrutura da página  
- **CSS3** – Estilo e layout responsivo  
- **JavaScript (ES6)** – Lógica e integração com API  
- **[ExchangeRate API](https://www.exchangerate-api.com/)** – Fonte das taxas de câmbio
